4. DETERMINISTIC INVARIANTS ENFORCED
================================================================================

- Debits == credits: runIntegrityGate (integrity_gate_service.ts) — getTrialBalanceTotals, then absGt(totalDebits, totalCredits, tolerance) -> trialBalanceBalances. assertIntegrityGateOrThrow throws MathematicalIntegrityError('A', ...). validateBalanced in journal_entry_service for JE lines.
- Assets == Liabilities + Equity: runIntegrityGate — balanceSheetGapExceeds = absGt(totalAssets, totalLiabilities+totalEquity, tolerance); balanceSheetBalances. Tolerance from getFinancialRules() (shared/config financial_rules.json) via getToleranceForGate().
- Plug detection: detectSuspiciousPlugs (integrity_gate_service.ts) — account names matching /^(Miscellaneous|Suspense|Other)(\s|$|\s*[-–—])/i; plugShare >= threshold (default 0.9) -> isSuspicious. finalIntegrityCheck calls it when entriesForPlugDetection provided; returns passed: false, plugSuspicious: true.
- Period lock mutation prevention: assertPeriodNotLocked (period_lock_service.ts) used in trial-balance ingest (ingest.ts), parser, close_closing_entries, close_adjustment_update_service; bridge (protocol_bridge.ts) for JE commands. Throws PeriodLockedError when lock exists for tenant/period.
- Certification gates: certifyCloseSession requires session.status === 'locked'; computeReadiness hardBlockers.length === 0; canPerform(actorRole, 'certify_close'); getAdjustedTrialBalance succeeds; buildCertifiedStatementsFromSnapshot(snapshotPayload) does not throw (Truth Gate).
- Truth Gate / final integrity: finalIntegrityCheck (integrity_check.ts) — runIntegrityGate (TB + BS), then detectSuspiciousPlugs if entriesForPlugDetection. buildCertifiedStatementsFromSnapshot (certified_statements_service.ts) runs finalIntegrityCheck and throws CertifiedIntegrityError on fail (TRIAL_BALANCE_IMBALANCED | BALANCE_SHEET_EQUATION_FAILED | PLUG_ACCOUNTS_DETECTED).
- Audit hash chain verification: verifyChain (audit_ledger_repository.ts) — SELECT audit_ledger by tenant_id ORDER BY created_at; for each row compute entry hash (computeEntryHashV1/V2), compare to entry_hash; verify previous_entry_hash links to prior. Returns valid: false on mismatch or broken link.
