# Historical audits and build reports

This folder contains the reviews, completion reports and point-in-time assessments that used to sit at the repository root.

They are kept because some of the findings and decisions still matter. They do not describe one consistent version of Sabit, and several reports disagree with one another. Do not use a file in this folder as proof of current readiness.

For current setup, start with the root README. Current status belongs in `PROJECT_STATUS.md` and should name the commit and checks it is based on.
